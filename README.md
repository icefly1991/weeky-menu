# 好好吃饭 · 一周菜单

一份夫妻两人份的家常周菜单，包含每日三餐、46 道可复用食谱、来源图片，以及按已安排菜单汇总的采购清单。

分享网址：https://icefly1991.github.io/weeky-menu/

这是公开查看版。菜谱可以搜索、按分类筛选，材料份量可以临时调整，采购项可以在自己的浏览器勾选。原菜单由发布者更新；Mealie 中的编辑不会自动同步到此页面。

无需服务器和安装依赖。直接打开 index.html 可查看。GitHub Pages 设置使用 main 分支的根目录。

数据在 data.js，界面在 index.html、style.css 和 app.js。仅包含发布所需的菜单与食谱内容，不包含 Mealie 凭据或数据库。

菜谱为简化改方，原食谱与图片来源在每道菜中标注。图片来自原网站，可能与改方不同，加载取决于来源网站。孕期食物安全与搭配参考链接见网页；没有核算个人热量与微量营养素需求。
