# 好好吃饭 · 一周菜单

一份夫妻两人份的家常周菜单，包含每日三餐、50 道可复用食谱、来源图片，以及按已安排菜单汇总的采购清单。

分享网址：https://icefly1991.github.io/weeky-menu/

这是公开查看版。菜谱可以搜索、按分类筛选，材料份量可以临时调整，采购项可以在自己的浏览器勾选。外食 block 只展示候选店名；周末预留一次家庭火锅。外食和尚未确定配料的火锅 block 不计入采购。原菜单由发布者更新；Mealie 中的编辑不会自动同步到此页面。

无需服务器和安装依赖。直接打开 index.html 可查看。GitHub Pages 设置使用 main 分支的根目录。

每周完整菜单和当时的食谱保存在 weeks/YYYY-MM-DD.js，周次索引在 weeks.js。页面优先显示当前周；当前周未安排时显示最近可用的周菜单。可通过选择周次翻看历史，链接中的 week 参数保存所选周次。data.js 保留为当前编辑数据的兼容导出。仅包含发布所需内容，不包含 Mealie 凭据或数据库。

编辑以 schedule 中的具体日期和餐次定位，星期显示由日期计算。将新周数据写成 JSON 后运行 node scripts/archive-week.cjs menu.json，只更新指定周，其他周文件保留。新周保存完整食谱快照，不会因以后改菜谱而改掉旧周内容。历史是计划记录；临时换餐需要同步修正才代表实际吃过的内容。

后续新增菜谱和调整菜单必须执行 [孕期菜单规则](MENU_RULES.md)；AGENTS.md 要求每次修改先读取规则。明确缺口补到下一顿，缺少个人目标或营养数据时不得宣称全部营养定量达标。

菜谱为简化改方，原食谱与图片来源在每道菜中标注。图片来自原网站，可能与改方不同，加载取决于来源网站。孕期食物安全与搭配参考链接见网页；没有核算个人热量与微量营养素需求。
